# 🃏 Game WNI Pack

Halo! Ini adalah proyek game kartu berbasis Python yang gua buat sendiri. Game ini seru banget dan murni menggunakan logika hitungan serta teks interaktif.

## 🚀 Fitur Utama Game:
* **Sistem Toko Potion:** Bisa beli ramuan buat nambah hoki/luck nambah pengalaman/exp dan nambah uang/money
* **Akumulasi Waktu Otomatis:** Kalau minum 2 ramuan sekaligus, durasinya otomatis bertambah panjang (numpuk)(masih tahap perkembangan)!
* **Bebas Freeze:** Game berjalan real-time pakai jam komputer asli (`time.time()`), jadi game gak bakal macet selama main.

## 🎮 Cara Main di Laptop mu
u:
1. Download file `main.py` yang ada di repositori ini.
2. Buka compiler Python favorit lu (seperti Programiz atau VS Code).
3. Jalankan kodenya dan selamat menikmati gamenya!
